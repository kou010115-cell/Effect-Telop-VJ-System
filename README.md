# あにてろ

アニソン系イベント向けの、テロップ表示アプリです（Windows・オフラインで動作）。
曲データベース（CSV）から曲を探して、作品名・曲名・アーティスト名を会場スクリーンにアニメーション付きで表示します。

## 主な機能

- 曲データベースの検索・登録・編集（`songs.csv`、Excel で直接編集も可）、CSV 取り込みと一括削除
- データベースにない曲の手入力表示
- 12 種類のテロップの動き（ランダム／順番／固定）、表示中の動きと出る動きの繰り返し
- 最初に画面中央へ「Title> / NOW PLAYING> / Artist>」を表示
- 2 画面対応（プロジェクターに映す出力ウィンドウ）、全画面表示
- 出力中の映像を映すステージと、次の曲のプレビュー（「動きを試す」はプレビューだけで再生）
- 1 行の案内（固定 2 パターン＋自由入力、赤ラベル）と、注意事項の表示
- 表示した曲の履歴（CSV で保存）

## 使い方

1. このリポジトリをダウンロードして展開します（Code → Download ZIP）
2. `あにてろを起動.vbs` をダブルクリックします（黒い画面は出ません）
3. 終了は操作画面のウィンドウを閉じるだけです

アイコン付きのショートカットは `ショートカットを作る.bat` で作れます。
詳しい使い方は [README.txt](README.txt) を見てください。

## 動作環境

- Windows 10 / 11（Windows PowerShell 5.1 と Microsoft Edge を使います。追加のインストールは不要）
